- your data: AutoTransformer is NOT the best here (no scaling wins by 0.192); biggest loss: KNN. Possible reason: when one large-valued column carries most of the signal (like ram in the phone data), unscaled distance-based models focus on it by luck, while any scaler gives the many noisy columns an equal vote (see Tasks 14, 26 and 29). Tree models are unaffected. This is a property of the data, not proof that scaling is wrong; compare per model before choosing.

HOW TO READ THIS
- If AutoTransformer is about equal to standard scaling on a dataset, the data was already well behaved; the pipeline did no harm.
- It should gain most where columns are skewed or have outliers, because there a single fixed scaler is the wrong choice.
- The thresholds (skew 1.0, outliers 2%, ...) are settings: change them and check the plan table; every decision has a written reason.
- Everything is learned on the training rows only when used inside a Pipeline (as in the cross-validation above), so there is no leakage.
- Limits: it looks at columns one at a time (not at relations between columns) and only handles numeric data; combine it with an encoder for categories (Task 15).
