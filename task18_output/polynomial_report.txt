SIMPLE EXPLANATION
- Polynomial features let a linear model learn curves, but features grow very fast (C(n+d, d) - 1).
- A high degree fits the training data better but the cross-validated score stops improving or drops: that is overfitting.
- PCA and SVD compress the features into fewer new columns (hard to interpret). SelectKBest and L1 keep a subset of the ORIGINAL polynomial terms (easier to interpret).
- If the true relationship is already almost linear (e.g. one feature explains the target well), higher degrees add little.
- Note: the base features were chosen with mutual information on ALL rows, which flatters the scores slightly. For a final model, do this selection inside the cross-validation.
