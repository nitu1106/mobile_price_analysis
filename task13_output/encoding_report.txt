COMPARISON
- One-hot: creates 98 columns (one per category). Easy to read ('city=Pune'), no assumptions about order, but the width explodes with many categories and most cells are 0.
- Target:  creates only 5 columns and packs the signal into one number. Strong when categories relate to the target, but harder to explain and it MUST be learned out-of-fold (otherwise the model sees the answer = data leakage).
- Frequency: creates 5 columns and ignores the target completely. It only helps when how COMMON a category is says something about the target. If categories are equally common, every value becomes the same number and the information is lost.

WHEN TO USE WHICH
- Few categories (< 10-15): one-hot.
- Many categories (high cardinality) and a clear target relation: target encoding (with smoothing + cross-fitting).
- Many categories and popularity matters (e.g. brand size): frequency encoding.
- Linear models need one-hot or target encoding; tree models can also handle frequency/ordinal codes.
